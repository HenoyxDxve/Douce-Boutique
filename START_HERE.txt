🚀 DÉMARRAGE RAPIDE
───────────────────────────────────────────────────────────────────────────────

OPTION 1: Script automatique (Recommandé - 5 minutes)
  Windows:  Double-cliquez setup.bat
  Linux:    chmod +x setup.sh && ./setup.sh
  Mac:      chmod +x setup.sh && ./setup.sh

OPTION 2: Manuel
  Frontend: npm install && npm run dev
  Backend:  cd backend && python -m venv venv
           source venv/bin/activate (ou venv\Scripts\activate.bat)
           pip install -r requirements.txt
           python manage.py migrate
           python init_db.py
           python manage.py runserver
